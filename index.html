LIBRARIAN

Проєкт «Librarian» — автономна система локального семантичного пошуку документів. Замість пошуку за ключовими словами програма використовує векторні представлення тексту (на основі моделі intfloat/multilingual-e5-small) та базу даних SQLite з розширенням sqlite-vec для знаходження файлів за їх змістом. Система працює виключно на локальному комп'ютері, не потребуючи підключення до інтернету. Це гарантує абсолютну конфіденційність даних та швидкий пошук файлів (≈0.2 секунди).

Основна ідея і результати

У сучасних умовах користувачі накопичують великі обсяги локальних текстових даних, якими стає складно керувати. Стандартні засоби пошуку операційних систем базуються виключно на точному збігу ключових слів. Якщо користувач формулює запит інакше або використовує синоніми, потрібний файл не буде знайдено. Основна ідея проєкту «Librarian» полягає у створенні швидкої, автономної та інтелектуальної системи семантичного пошуку, яка орієнтується на контекст та загальний зміст документа. Для вирішення проблеми розроблено алгоритм на основі векторних представлень тексту. У реалізації використано мову програмування Python, базу даних sqlite з розширенням sqlite-vec, модель для ембеддингу intfloat/multilingual-e5-small, а також фреймворк flet для інтерфейсу. Під час індексації програма сканує вибрану директорію та виявляє файли форматів txt, pdf та docx. Для оптимізації ресурсів система перевіряє час останньої зміни файлів та індексує лише нові або змінені документи. Зчитаний текст автоматично розбивається на фрагменти для збільшення точності пошуку. Після цього кожен фрагмент опрацьовується через локальну багатомовну модель intfloat/multilingual-e5-small. Модель перетворює текст у числовий вектор розмірністю 384 елементи. Отриманн
